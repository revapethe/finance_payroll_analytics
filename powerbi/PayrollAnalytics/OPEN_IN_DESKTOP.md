# Open this Power BI project

The report pages, visuals, model relationships and measures are preconfigured. Use the Desktop handoff ZIP to obtain the matching CSVs, or generate the package using the repository tools. The package includes START_HERE.md with opening instructions.

By default the CSV model looks in C:\PayrollAnalytics\data. If the files are elsewhere, change the DataFolder parameter in Power BI Desktop and refresh. Keep PayrollAnalytics.pbip, PayrollAnalytics.Report, PayrollAnalytics.SemanticModel and data together.

Project files are schema-validated; Desktop refresh and rendering have not been run in this Linux task. A finished PBIX and Power BI Service deployment are not included.
